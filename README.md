# octreg

Label-free affine registration of an OCT block to an MRI of the same specimen.

The 1.0 release is being built on this branch and nothing here runs yet. The method, code layout, validation plan and documentation plan are in [docs/design/spec_v1.0.md](docs/design/spec_v1.0.md). The previous research code (v1.1) is kept at the git tag `v1.1-archive`, and its documents are in [docs/archive/](docs/archive/).
